# 🎥 CineGuide - La révolution du streaming

CineGuide est votre guide ultime pour le streaming de films et séries. Notre application vous permet de :

- Découvrir les films et séries les plus populaires
- Rechercher facilement vos contenus préférés
- Voir où regarder légalement vos films et séries préférés
- Obtenir des informations détaillées (synopsis, acteurs, bandes-annonces)
- Suivre les tendances du moment
- Explorer par genres et catégories

Tout cela en français, avec une interface intuitive et moderne.

## 🎬 Powered by TMDB

CineGuide utilise l'API The Movie Database (TMDB) pour vous offrir :

- Une base de données complète de films et séries
- Des informations détaillées sur les contenus (cast, équipe, bandes-annonces)
- Les plateformes de streaming disponibles
- Des images haute qualité (affiches, photos)
- Des données mises à jour quotidiennement
- Une localisation en français
